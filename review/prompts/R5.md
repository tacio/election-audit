# Round 5: verification of fixes

Read the Round 1 instructions in `review/prompts/R1.md` in this checkout; the same rules
apply. This checkout is at the commit after the fixes. The ledger rows after the packet
below are the findings Claude confirmed. Each row's `commits` field lists the commits
meant to fix it.

For each row, read the diff and the new tests, then run the tests. Answer with one of:

- `fixed`: the defect is gone, and a test fails without the fix.
- `not-fixed`: say what remains.
- `regressed`: the fix broke something else; say what.

Put each answer in `responses`, with `finding_id` set to the row's `id`. Report new
findings only in the code the fix range changed. Your final message must be the JSON
object required by the schema, and nothing else.
