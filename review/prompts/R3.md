# Round 3: challenge

Read the Round 1 instructions in `review/prompts/R1.md` in this checkout; the same rules
apply. Between rounds, Claude, the author of this code, triaged every finding of both
reviewers into the ledger rows listed after the packet below. Each row has a
`disposition` and a `rationale`. Many rows also have `reproduction`: the test or command
Claude used, and its result.

The dispositions are:

- confirmed
- partly-confirmed
- rejected
- duplicate
- known-gap
- needs-user
- out-of-scope

Your task in this round:

1. Rows that came from you, other than confirmed ones: re-check the cited evidence
   yourself. If you think the rationale is wrong, answer `contest` with a concrete
   counter-argument: the code path, input or test that defeats it. If the rationale is
   right, answer `accept-disposition`. Do not concede to authority, and do not insist
   without new evidence.
2. Rows that came only from the other reviewer: answer `agree` or `disagree` after
   checking them yourself. Add which part you checked.
3. New findings: only if severity is high or critical and the ledger does not already
   hold them. Otherwise leave `findings` empty.

Put each answer in `responses`, with `finding_id` set to the ledger row's `id`. Your
final message must be the JSON object required by the schema, and nothing else.
