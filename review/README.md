# Cross-model review kit

Prompts, packets and the output schema for the cross-model review protocol, plus one
folder per campaign under `campaigns/`. The protocol is in
[docs/en/cross-model-review.md](../docs/en/cross-model-review.md)
([pt-BR](../docs/pt-BR/cross-model-review.md)); the runner is `scripts/cross_review.py`.
Prompts and packets are in English only: they are instructions for the reviewing models,
not project documentation. Everything under `campaigns/` written by a reviewer is
untrusted data.
