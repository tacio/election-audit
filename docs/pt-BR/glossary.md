# Glossário

Document-ID: EA-GLOSSARY · Revision: 1 · Language: pt-BR

[English](../en/glossary.md)

| English | Português | Significado |
| --- | --- | --- |
| election | eleição | Escopo oficial de ano/pleito/eleição/turno. |
| contest | disputa | Cargo e jurisdição dentro da eleição. |
| registered section | seção registrada | Integrante administrativa antes da agregação. |
| principal section | seção principal | Seção terminal responsável pelo eleitorado composto. |
| composition crosswalk | correspondência de composição | Atribuição integrante-principal por snapshot; não multiplica votos. |
| polling location | local de votação | Local delimitado por eleição; agrupamento de divisões/pares. |
| candidacy | candidatura | Identidade oficial do candidato por disputa. |
| vote choice | escolha de voto | Candidato ou categoria branco/nulo/especial/não resolvido. |
| physical device | dispositivo físico | Identidade física comprovada, separada de modelo/software. |
| software configuration | configuração de software | Identidade de versão/build/configuração observada. |
| source object | objeto de origem | Bytes originais exatos identificados por SHA-256 local. |
| source observation | observação de origem | Tentativa imutável de observar mapeamento URL-objeto. |
| source package | pacote de origem | Contexto oficial de pacote; ID não é presumido resumo dos bytes. |
| snapshot | snapshot | Inventário, população esperada e política congelados. |
| result version | versão de resultado | Observação imutável de BU/resultado, inclusive conflitos/correções. |
| canonical result | resultado canônico | Uma versão elegível por snapshot/principal/disputa. |
| voting session | sessão de votação | Sessão operacional física reconstruída; pode atravessar pacotes. |
| anonymous cycle | ciclo anônimo | Ciclo operacional sem identidade de candidato ou eleitor. |
| lineage | linhagem | Vínculos da linha derivada ao objeto/membro/registro original. |
| readiness | prontidão | Disponibilidade por atributo/unidade após validar entradas e denominador. |
| receipt / processing | recebimento / processamento | Eventos distintos do ciclo do publicador. |
| generation / publication | geração / publicação | Criação do artefato e disponibilidade pública; eventos distintos. |
| observation | observação | Horário do cliente, não horário do evento de origem. |
| device time | horário do dispositivo | Leitura ingênua original antes de conversão validada. |
| after17 | after17 | Conclusão doméstica estritamente após 17:00:00 Brasília; exterior separado. |
| strict unanimity | unanimidade estrita | Total positivo, todos os votos para um candidato, sem outras categorias. |
| exchangeability | permutabilidade | Hipótese amostral de calibração por postos; agrupamentos não a garantem. |
| FDR | FDR | Fração esperada de rejeições falsas entre rejeições, zero se nenhuma; não probabilidade de fraude. |
| conditional impact bound | limite condicional de impacto | Faixa aritmética sob mecanismo/população/limite explícitos. |

Identificadores de código/tabela/campo são iguais nos dois idiomas; traduções
explicam significados sem renomear interfaces públicas. Veja o [dicionário](schema-dictionary.md).
